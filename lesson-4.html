列表

一组数据的容器——索引、切片、方法与排序

🎯 本节目标
  • 会用 [] 创建列表、索引访问、负索引
  • 会用 append/insert/pop/del 增删改
  • 会切片 lst[start:end:step]（左闭右开）
  • 会用 len/max/min/sum/sort/reverse 等

📖 知识点 读一读，会的就点「已会」

知识点 1创建列表与访问
💡 列表像一排带编号的储物格，编号从 0 开始数。

用 [] 装一组数据，元素用逗号隔开。

numbers = [1, 1, 3, 4, 7, 11]
animals = ["dog", "pig", "cat", "bird"]
print(len(numbers))   # 6（长度）
print(numbers[0])     # 1（第一个，索引从 0 起）
print(numbers[-1])    # 11（最后一个，负索引 -1 起）

正索引从 0 起，负索引从 -1 起；len() 返回元素个数。

知识点 2增删改
💡 append 往后塞、insert 插队、pop 拿走并告诉你拿了啥。

列表是可变的，能直接增、删、改。

animals = ["dog", "pig", "cat", "bird"]
animals[0] = "mouse"     # 改第一个
animals.append("duck")    # 末尾追加
animals.insert(1, "cow")  # 在索引1处插入
del animals[2]            # 删除索引2
popped = animals.pop()    # 删最后一个并返回
print(animals)
print(popped)

del 不返回值；pop() 返回被删除的元素（默认删最后一个）。

知识点 3切片
💡 切蛋糕：从 start 切到 end 前面一块（左闭右开）。

取一段：list[start:end:step]。

lst = [1, 2, 3, 4, 5, 6]
print(lst[2:5])     # [3,4,5]（含2不含5）
print(lst[:4])      # [1,2,3,4]
print(lst[3:])      # [4,5,6]
print(lst[::-1])    # 反转
print(lst[::2])     # 步长2：隔一个取

左闭右开：冒号左边含、右边不含。这是最容易错的地方。

知识点 4常用函数与方法
💡 len/max/min/sum 一键统计；count 数个数；sort 排序。

统计、排序、查找一网打尽。

nums = [2, 5, 6, 7, 8, 9, 2, 9, 9]
print(max(nums))        # 9
print(min(nums))        # 2
print(sum(nums))        # 57
print(nums.count(9))    # 3
nums.sort()             # 原地升序
print(nums)
nums.sort(reverse=True) # 原地降序
print(nums)

sort()/reverse() 原地修改，返回 None；不会返回新列表。

知识点 5+ * in
💡 + 拼在一起、* 复制几份、in 问『在不在』。

拼接、重复、成员判断。

a = [1, 2, 3]
b = [4, 5, 6]
print(a + b)     # [1,2,3,4,5,6]（新列表）
print(a * 2)     # [1,2,3,1,2,3]
print(2 in a)    # True
print(9 in a)    # False

+ 和 * 生成新列表、不改原列表；in 常配合 if 使用。

📌 老师注记
  • 要点：用『行李架/储物柜』比喻列表与索引，孩子容易理解。
  • 要点：切片左闭右开是重点，反复用例子强化。
  • 常见错误：以为切片含右边终点，实际不含。
  • 常见错误：sort()/reverse() 直接写 print(lst.sort()) 会打印 None。

📝 本课作业

第 1 题

运行下列代码，输出的结果是（　）。 fruits = ["苹果","梨","西瓜","香蕉","橘子"] fruits.append("桃") fruits.insert(2, "龙眼") fruits.pop(1) print(fruits)

  • A. ['苹果','梨','西瓜','香蕉','橘子']
  • B. ['苹果','龙眼','西瓜','香蕉','橘子','桃']
  • C. ['苹果','梨','龙眼','西瓜','香蕉','橘子']
  • D. ['桃','苹果','梨','龙眼','西瓜','香蕉']
展开参考答案
答案：B
append 加 '桃'，insert(2,'龙眼')，pop(1) 删掉索引 1 的 '梨'。
第 2 题

运行下列代码，输出的结果是（　）。 numbers = [3, 4, 2, 99, 33] numbers.sort() print(numbers[3])

  • A. 2
  • B. 33
  • C. 4
  • D. 99
展开参考答案
答案：B
sort 后为 [2,3,4,33,99]，索引 3 是 33。
第 3 题

运行下列代码，输出的结果是（　）。 A = [1, 2, 3, 4] print(A[2:])

  • A. 2
  • B. [3]
  • C. [2,3,4]
  • D. [3,4]
展开参考答案
答案：D
A[2:] 从索引 2 取到结尾，即 [3,4]。
第 4 题

创建列表 Num = [2, 1, 9, 4, 7, 11]，写出：长度、最大值、最小值、总和。

展开参考答案
答案：len=6；max=11；min=1；sum=34
用 len()/max()/min()/sum()。
第 5 题

对列表 Num = [2, 1, 9, 4, 7, 11]：先升序排序，再反转，打印两次结果。

展开参考答案
答案：Num = [2, 1, 9, 4, 7, 11] Num.sort() print(Num) # [1, 2, 4, 7, 9, 11] Num.reverse() print(Num) # [11, 9, 7, 4, 2, 1]
sort() 升序，reverse() 反转，都是原地修改。
