分支结构 if / elif / else

让程序会『思考』——条件判断与嵌套

🎯 本节目标
  • 掌握 if/elif/else 语法，注意冒号和缩进
  • 会写嵌套分支
  • 会用 and/or 组合多条件

📖 知识点 读一读，会的就点「已会」

知识点 1if —— 岔路口
💡 if 是岔路口，看条件决定走哪条路。

条件为真走 if 块，否则依次判断 elif，最后走 else。

score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("再加油")

条件后必须有冒号 :，代码块必须缩进（4 空格或 1 Tab）。

知识点 2多条件 & 嵌套
💡 条件往往是『比较』或『逻辑』的结果；路口里还能有小路口。

用 and/or 组合，或用嵌套 if。

age = 15
gender = "男"
if gender == "男" and age < 18:
    print("男孩")
elif gender == "男" and age >= 18:
    print("男人")
elif gender == "女" and age < 18:
    print("女孩")
else:
    print("女人")

多条件用 and/or 连接，或拆成嵌套分支，两种写法都对。

知识点 3实例：出租车计费
💡 从小到大分段判断，先判断近距离，别漏判。

分段计价：一段一个价。

km = int(input("请输入距离(km): "))
if km <= 3:
    cost = 10
elif km <= 16:
    cost = 10 + (km - 3) * 2.7
else:
    cost = 10 + (16 - 3) * 2.7 + (km - 16) * 3
print(cost)

验证：2→10；12→34.3；25→72.1。多分支要按顺序写，否则漏判。

📌 老师注记
  • 要点：分支的本质是『根据不同情况走不同路线』。
  • 要点：先判断范围再进行下一步，顺序很关键。
  • 常见错误：忘写冒号 : 或缩进不对，导致语法错误。
  • 常见错误：elif 条件顺序写反，导致永远进不了某些分支。

📝 本课作业

第 1 题

输入成绩：≥90 输出 A，80-89 输出 B，70-79 输出 C，60-69 输出 D，<60 输出 E。

展开参考答案
答案：score = int(input()) if score >= 90: print("A") elif score >= 80: print("B") elif score >= 70: print("C") elif score >= 60: print("D") else: print("E")
多分支从大到小排列，避免漏判。
第 2 题

输入性别（男/女）和年龄，输出称呼：男&&<18→男孩，男&&≥18→男人，女&&<18→女孩，女&&≥18→女人。

展开参考答案
答案：gender = input() age = int(input()) if gender == "男": if age < 18: print("男孩") else: print("男人") else: if age < 18: print("女孩") else: print("女人")
嵌套分支或 and 组合均可。
第 3 题

出租车计费：≤3 公里 10 元；3-16 公里超出部分每公里 2.7 元；>16 公里超出部分每公里 3 元。输入路程，输出费用。

展开参考答案
答案：km = int(input()) if km <= 3: cost = 10 elif km <= 16: cost = 10 + (km - 3) * 2.7 else: cost = 10 + (16 - 3) * 2.7 + (km - 16) * 3 print(cost)
验证：2→10，12→34.3，25→72.1。
