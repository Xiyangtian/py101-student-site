变量与数据类型

变量、命名、注释，以及四大基本类型

🎯 本节目标
  • 理解变量，掌握命名规则与保留字
  • 会用 单行# 和 多行三引号 注释
  • 认识字符串/整数/浮点数/布尔四种类型
  • 会用 str/int/float/bool 做类型转换

📖 知识点 读一读，会的就点「已会」

知识点 1变量 —— 电脑的碗
💡 碗是一样的碗，贴的标签（变量名）不一样，装的东西也不一样。

变量像一个贴了标签的碗，用来存数据，通过名字访问。

name = "小明"     # 字符串
grade = 13        # 整数
tall = 1.55       # 浮点数
print("我叫", name, "今年", grade, "岁")

= 是赋值，把右边数据存进左边变量。变量要先赋值再用。

知识点 2变量命名规则
💡 名字要像路牌：别人看得懂、不撞名、不打头阵用数字。

字母、数字、下划线；数字不能开头；不能用保留字。

# 合法：
my_name = "Tom"
_score2 = 90

# 非法：
# 1name = 5   数字开头 ❌
# if = 5      保留字 ❌
# my-name = 5 含短横线 ❌

不能用保留字（if、while、True、False等）做变量名；区分大小写。

知识点 3注释 —— 给代码写说明
💡 # 是单行便签；三个引号是整段便签。

注释不会被执行，只给人看。

# 这是单行注释（用 # 开头）
print("你好")   # 行尾也可以

"""
这是多行注释
用三个双引号或单引号包围
"""

考试常考：单行注释用 #，多行用三引号。双引号是字符串，不是注释。

知识点 4四大基本数据类型
💡 文字要引号、数字分两种（带不带小数点）、真假是开关、空心是 None。

字符串、整数、浮点数、布尔。

s = "Hello"      # 字符串 str
n = 42           # 整数 int
f = 3.14         # 浮点数 float
b = True         # 布尔 bool（True/False）
none = None      # 无值

字符串可 + 拼接、\n 换行；用 type(x) 查看类型。

知识点 5类型转换 —— 翻译官
💡 str/int/float/bool 是四个翻译官，把一种类型翻译成另一种。

在字符串、整数、浮点数、布尔之间互相转换。

age = 14
print("你今年" + str(age) + "岁")

a = int("123")       # 字符串→整数
b = float(4)         # 整数→浮点数 4.0
print(int(3.6))      # 3（截断，不是四舍五入）
print(bool(0))       # False
print(bool(" "))     # True（含空格的字符串为真）

int("3.5") 会报错，需先 float() 再 int()；float→int 是截断。

📌 老师注记
  • 要点：把变量比作『贴了标签的盒子』，孩子容易理解。
  • 要点：强调 input() 得到的是字符串，要算数得转 int/float。
  • 常见错误：int("3.5") 报错——应写成 int(float("3.5"))。
  • 常见错误：把 str(age) 忘掉，直接字符串+数字导致报错。

📝 本课作业

第 1 题

选项中，常用于 Python 语言注释的符号不包括（　）。

  • A. # 井号
  • B. "" 双引号
  • C. 三引号 """
  • D. 单引号三引号 '''
展开参考答案
答案：B
双引号用于字符串，不是注释；# 单行注释，三引号多行注释。
第 2 题

下列选项中，不属于字符串类型的是（　）。

  • A. 'apple'
  • B. "banana"
  • C. "'pear"
  • D. #peach
展开参考答案
答案：D
# 开头的 #peach 是注释，不是字符串字面量。
第 3 题

选项中，不能直接转换为整型的是（　）。

  • A. "四十一"
  • B. 4
  • C. 2.33
  • D. True
展开参考答案
答案：A
int() 无法把中文数字“四十一”转成整数。
第 4 题

选项中不符合 Python 变量命名规则的是（　）。

  • A. a1b2
  • B. William Shakespear
  • C. _2x
  • D. For
展开参考答案
答案：D
变量名不能含空格，For 里有空格所以不合法。
第 5 题

选项中变量名在 Python 程序中合法的是（　）。

  • A. 123_abc
  • B. _cat_
  • C. #dog
  • D. while
展开参考答案
答案：B
123_abc 以数字开头；#dog 含非法字符 #；while 是保留字。
第 6 题

写出结果：print(type(3))、print(type(3.0))、print(type("3"))。

展开参考答案
答案：int / float / str
type() 返回数据类型：3 是 int，3.0 是 float，"3" 是 str。
第 7 题

写一个“个人信息录入”程序：输入姓名、年龄、身高，按固定格式输出（用到 str/int/float 转换）。

展开参考答案
答案：name = input("请输入姓名: ") age = int(input("请输入年龄: ")) height = float(input("请输入身高(米): ")) print("姓名:" + name + " 年龄:" + str(age) + " 身高:" + str(height))
input 得到字符串，算数和拼接前要转换类型。
