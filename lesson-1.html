让电脑开口说话

print、input、变量、IPO——第一步让电脑听懂你

🎯 本节目标
  • 知道 Python 是什么，理解解释型/编译型语言的区别
  • 写出第一个程序：print() 输出
  • 理解 IPO 模型：输入→处理→输出
  • 认识变量与基本数据类型

📖 知识点 读一读，会的就点「已会」

知识点 1Python 是什么？
💡 Python 像一门『普通话』，你写一行，电脑就照着做一行。

Python 是一门编程语言，是计算机能读懂的语言。

# 输出一句话到屏幕
print("Hello World")

# 也可以输出算好的结果
print(1 + 2)

print() 就是把内容显示到屏幕的指令。Python 是解释型：一句一句边解释边执行。

知识点 2print —— 电脑的大喇叭
💡 print = 电脑拿大喇叭喊话，喊的内容要加引号告诉电脑『这是文字』。

print() 把括号里的内容打印到屏幕上。

# 第一个程序
print("Hello World")
print(1 + 2)

print 里放字符串要加引号；放数字直接写。中文输出也不难。

知识点 3input —— 电脑的耳朵
💡 input 是耳朵，print 是嘴巴。电脑等你说完再回应。

input() 接收键盘输入；得到的一定是字符串。

name = input("请输入你的名字: ")
print("你好, " + name)

a = int(input("请输入一个整数: "))
print("你输入的数是", a)

input() 返回字符串，要当数字算得先用 int()/float() 转。

知识点 4IPO —— 程序的骨架
💡 写程序先想三件事：要什么输入、怎么处理、要什么输出。

I 输入 → P 处理 → O 输出。

I nput (输入) ──► P rocessing (加工) ──► O utput (输出) input() 运算 / 判断 / 循环 print()
知识点 5变量 & 冯·诺依曼
💡 变量 = 贴上名字标签的碗；电脑 = 输入→存储→运算→控制→输出。

变量是装数据的容器；了解电脑的经典结构。

冯·诺依曼体系结构 （存储程序 + 五大部件）├── 输入设备 （键盘鼠标）├── 存储器 （存程序和数据）├── 运算器 （做运算）├── 控制器 （指挥）└── 输出设备 （显示器）
📌 老师注记
  • 要点：第一课重点是『能跑起来』，让学生成功运行第一个程序比讲完理论更重要。
  • 要点：用 print/input 反复演示，让学生感受到『代码→运行→结果』。
  • 常见错误：以为 input() 直接得到数字，其实得到的是字符串，需要 int()/float() 转换。
  • 常见错误：变量名用数字开头或用关键字导致语法报错。

📝 本课作业

第 1 题

在 Python 语言中，下列说法正确的是（　）。

  • A. range 是一个关键字
  • B. IPO 程序编写方法包括输入、处理和输出
  • C. 程序结构只有分支结构和循环结构两种
  • D. Python 只能在 Windows 环境下运行
展开参考答案
答案：B
range 是内置函数不是关键字；程序结构有三种（顺序、分支、循环）；Python 跨平台。
第 2 题

运行 print("Hello World")，屏幕会输出（　）。

  • A. Hello World
  • B. 'Hello World'
  • C. 程序报错
  • D. 没有输出
展开参考答案
答案：A
print 把引号里的内容打印到屏幕，输出 Hello World。
第 3 题

用 input() 获取到的数据，类型是（　）。

  • A. 整数
  • B. 浮点数
  • C. 字符串
  • D. 布尔
展开参考答案
答案：C
input() 返回的一定是字符串，要当数字用需 int()/float() 转换。
第 4 题

IPO 中 I、P、O 分别代表（　）。

  • A. 输入、处理、输出
  • B. 输出、处理、输入
  • C. 输入、输出、处理
  • D. 输入、存储、输出
展开参考答案
答案：A
I 输入(input) → P 处理(processing) → O 输出(output)。
第 5 题

现代计算机之父是 ______（人名），他提出的结构叫 ______。

展开参考答案
答案：冯·诺依曼；冯·诺依曼体系结构
常考常识题。
第 6 题

计算机发展经历了 ______ 代，第二代的电子元件是 ______。

展开参考答案
答案：四；晶体管
第一代电子管，第二代晶体管，第三代中小规模集成电路，第四代大规模/超大规模集成电路。
第 7 题

写一个程序：用 input() 让用户输入自己的名字，再用 print() 输出“你好，XXX！”

展开参考答案
答案：name = input("请输入你的名字: ") print("你好, " + name)
注意 input() 得到的是字符串。
