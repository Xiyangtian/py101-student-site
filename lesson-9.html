异常处理 & 真题实战

try-except、eval，综合应对真题编程题

🎯 本节目标
  • 会用 try-except 处理输入异常
  • 会用 eval() 把字符串当表达式计算
  • 能综合运用 IPO、分支、循环、列表应对真题编程题

📖 知识点 读一读，会的就点「已会」

知识点 1try-except —— 护身符
💡 把可能出错的地方『护起来』，出错也不让程序崩溃。

可能出错的地方用 try 包起来，出错走 except。

try:
    a = float(input("请输入数值: "))
    print("你输入的是", a)
except:
    print("输入有误，请重新输入")

输入『好的』时 float() 会报错，被 except 捕获，提示重输而不是崩溃。

知识点 2循环到输入正确
💡 直到学生做对为止——不停问，问对了才放行。

while True + try-except，直到输入合法。

while True:
    try:
        x = int(input("请输入一个整数: "))
        print(x)
        break
    except:
        print("输入的不是整数，请重试")

输入非法就 except，循环继续；输入合法就 break 结束。

知识点 3eval —— 当算式算
💡 eval 把字符串『当算式』算出来，一行顶一堆代码。

把字符串当作表达式执行并返回结果。

print(eval("2 + 3"))      # 5
print(eval("3 * 4"))       # 12
expr = input("输入算式: ")
print("结果:", eval(expr))

考试中了解它会计算字符串表达式即可。

知识点 4真题编程题
💡 操作题拿分关键是『能跑通』，先看清输入/输出格式再动手。

读题→拆解→写码→跑通。

# ① 两数之差与和
a = int(input()); b = int(input())
print(abs(a - b)); print(a + b)

# ② 评委平均分
s = input(); nums = list(map(int, s.split()))
print(round(sum(nums)/len(nums)))

# ③ 最小公倍数
a,b = int(input()), int(input())
gcd = max(i for i in range(1, min(a,b)+1) if a%i==0 and b%i==0)
print(a*b//gcd)

① abs 差值；② split+map+round；③ 两数之积 ÷ 最大公约数。

📌 老师注记
  • 要点：异常处理用『输入非数字』的场景讲最直观。
  • 要点：真题操作题重点练：累加、平均、最大最小、最小公倍数、循环遍历。
  • 常见错误：不捕获异常，程序一输错就崩溃退出。
  • 常见错误：操作题输入输出格式不符，比如多打印提示文字导致判分错误。

📝 本课作业

第 1 题

运行下列代码，输入“好的”则输出结果是（　）。 try: a = float(input("请输入数值: ")) except: print("输入有误") else: print(a)

  • A. 我不知道
  • B. 输入有误
  • C. 请输入数值
  • D. 没有输出结果
展开参考答案
答案：B
float("好的") 会报错，被 except 捕获，输出“输入有误”。
第 2 题

写一个 try-except 程序：让用户反复输入整数，直到输入合法才结束。

展开参考答案
答案：while True: try: x = int(input()) print(x) break except: print("输入的不是整数，请重试")
try 里放可能出错的操作，except 处理异常。
第 3 题

用 eval 计算用户输入的一个表达式（如 2*3+4）。

展开参考答案
答案：expr = input("输入算式: ") print(eval(expr))
eval 把字符串当表达式计算。
第 4 题

真题·分别输入两个正整数，输出两数的差（大数减小数）与两数的和。

展开参考答案
答案：a = int(input()) b = int(input()) print(max(a, b) - min(a, b)) print(a + b)
用 max/min 求大数减小数。
第 5 题

真题·输入 5 个评委的分数（空格隔开），输出平均分（四舍五入到整数）。

展开参考答案
答案：s = input() nums = list(map(int, s.split())) print(round(sum(nums) / len(nums)))
split() 拆分，map(int) 转整数，round() 四舍五入。
第 6 题

真题·输入两个正整数，输出它们的最小公倍数。

展开参考答案
答案：a, b = int(input()), int(input()) # 先求最大公约数 for i in range(1, min(a, b) + 1): if a % i == 0 and b % i == 0: gcd = i print(a * b // gcd)
最小公倍数 = 两数之积 // 最大公约数。
