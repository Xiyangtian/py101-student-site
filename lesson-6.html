循环结构 while / for

让程序重复做——while、for、range、break/continue

🎯 本节目标
  • 会用 while 循环，理解 while True + break
  • 会用 for 遍历，用 range() 生成序列
  • 掌握 break（结束）与 continue（跳过）
  • 会写嵌套循环：直角三角形、九九乘法表

📖 知识点 读一读，会的就点「已会」

知识点 1while —— 一直做
💡 只要『条件还成立』，就一直重复；记得让条件能变假，否则死循环。

条件为真就一直循环，直到条件变假。

n = 0
while n < 5:
    print("第", n, "次")
    n = n + 1    # 别忘了让 n 变化

# 密码验证
while input("请输入密码: ") != "cubicbird":
    print("密码错误")
print("密码正确")

循环体里一定要有让条件最终变假的语句，否则死循环。

知识点 2for + range
💡 for 像点名：按顺序一个一个叫出来。

for 挨个取出元素；range 生成一串整数。

for fruit in ["apple", "banana", "cherry"]:
    print(fruit)

for i in range(5):        # 0,1,2,3,4
    print(i)

for i in range(2, 9, 3):  # 2,5,8（不含9，步长3）
    print(i)

range(start,stop,step) 左闭右开，不含 stop；range(n) 默认 0 起、步长 1。

知识点 3break 与 continue
💡 break 是大结局，continue 是插队跳过这一轮。

break 结束整个循环；continue 跳过本次。

# break：到 3 就停
for i in range(10):
    if i == 3:
        break
    print(i)   # 0 1 2

# continue：跳过 3 的倍数
for i in range(1, 7):
    if i % 3 == 0:
        continue
    print(i)   # 1 2 4 5

口诀：break 结束整个循环，continue 跳过本次进入下一次。

知识点 4循环嵌套
💡 外层管『行』，内层管『列』。

循环里再套循环。

# 直角三角形
n = int(input("输入行数: "))
for i in range(1, n + 1):
    print("*" * i)

# 九九乘法表
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}*{i}={j*i}", end=" ")
    print()

end="" 让输出不换行；外层控制行、内层控制列。

知识点 5累加求和
💡 先准备一个空碗 total，一次次往里加。

循环 + 累加器，最常用套路。

total = 0
for i in range(1, 101):
    total += i
print(total)   # 5050

total = 0
for num in range(200, 501):
    total += num
print(total)   # 105350

累加器 total 循环前要初始化为 0；range 不含结束值。

📌 老师注记
  • 要点：用『重复做一件事』引入循环最直观，先演示再讲语法。
  • 要点：先讲 for+range，再讲 while，孩子更容易上手。
  • 常见错误：忘记给循环变量变化导致死循环。
  • 常见错误：range 的结束值含不含搞不清（不含）。
