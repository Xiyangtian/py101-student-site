运算符与表达式

算术、比较、逻辑运算符与优先级

🎯 本节目标
  • 会用 + - * / % // ** 做算术
  • 会用 == != > < >= <= 比较，返回 True/False
  • 会用 not and or 组合条件
  • 掌握优先级与结合性

📖 知识点 读一读，会的就点「已会」

知识点 1算术运算符
💡 数学课老朋友，新认识 // （整除）和 % （取余）。

做数学运算，返回数值。

print(5 + 3)     # 8
print(5 / 3)     # 1.6666...（除法是浮点数）
print(5 % 3)     # 2（取余）
print(5 ** 3)    # 125（幂）
print(7 // 2)    # 3（整除向下）

% 常用来判断奇偶/整除；/ 结果一定是浮点数。

知识点 2比较运算符
💡 只回答『是/否』的问题：是否相等、谁大谁小。

比较两值，返回布尔 True/False。

print(5 == 3)   # False（等于）
print(5 != 3)   # True（不等于）
print(5 > 3)    # True
print(5 >= 5)   # True
print(3 <= 1)   # False

= 赋值，== 比较。3 == "3" 结果是 False（类型不同）。

知识点 3逻辑运算符
💡 and 要都对、or 有一个对就对、not 反过来。

组合多个条件，常用于 if。

print(not True)          # False
print(True and False)   # False
print(True or False)    # True

# 短路：and 左假不再算右边；or 左真不再算右边
print(False and (1/0))  # 不报错，右边没执行

短路特性常考：False and 后面写什么都没关系，不会执行。

知识点 4优先级
💡 拿不准就加括号，最保险也最好读。

从高到低：括号 > 幂 > 乘除 > 加减 > 比较 > 逻辑。

print(2 + 3 * 4)      # 14：先乘后加
print((2 + 3) * 4)    # 20：括号优先
print(2 ** 3 ** 2)    # 512：幂是右结合
print(8 - 3 + 2)      # 7：左结合

算术左结合、幂右结合；把不确定的用括号包起来。

📌 老师注记
  • 要点：用『% 取余』判断奇偶、整除，是考试高频用法。
  • 要点：and/or/not 常与 if 结合使用，要配合 L5 一起讲。
  • 常见错误：把 = 当比较用，写成 if x = 5（应该是 ==）。
  • 常见错误：35/6 得到浮点数，做 int() 时忘记先算对。

📝 本课作业

第 1 题

运行下列代码，输出的结果是（　）。 print(1 <= 2, 2 == 3)

  • A. None
  • B. False False
  • C. False True
  • D. True False
展开参考答案
答案：D
1<=2 为 True，2==3 为 False。
第 2 题

运行下列代码，输出的结果是（　）。 x = 3 x = x * 6 + 1 print(x)

  • A. 4
  • B. 7
  • C. 19
  • D. 21
展开参考答案
答案：C
3*6+1=19。
第 3 题

表达式 7 // 2 的值是（　）。

  • A. 3.5
  • B. 3
  • C. 4
  • D. 7
展开参考答案
答案：B
// 是整除（向下取整），7//2=3。
第 4 题

运行以下代码，输出的结果是（　）。 print(int(15/6 + 3.3))

  • A. 1
  • B. 5
  • C. 5.8
  • D. 6
展开参考答案
答案：B
15/6=2.5，2.5+3.3=5.8，int(5.8)=5。
第 5 题

运行下列代码，输出的结果是（　）。 a = int(5.8) > int(5.4) b = 5.8 > 5.4 print(a and b)

  • A. 1
  • B. False
  • C. True
  • D. 程序出错
展开参考答案
答案：B
int(5.8)=5,int(5.4)=5，5>5 为 False；b 为 True；False and True=False。
第 6 题

运行下列代码，输出的结果是（　）。 a, b = 4, 5 print((a == b) + (a <= b) + (a >= b) + (a != b))

  • A. 0
  • B. 1
  • C. 2
  • D. 3
展开参考答案
答案：C
False+False+True+True = 0+0+1+1 = 2。
第 7 题

写一个程序：输入一个整数，并判断它是否为偶数（用 % 和 ==），输出“偶数/奇数”。

🖥️ 打开编程页面 ›
展开参考答案
答案：n = int(input()) if n % 2 == 0: print("偶数") else: print("奇数")
n % 2 == 0 表明能被 2 整除。
