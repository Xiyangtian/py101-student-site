字符串与列表的操作

共有操作、split/join、字符串与列表互转

🎯 本节目标
  • 掌握字符串与列表共有操作：+ * 切片 in for
  • 掌握字符串特有操作：split() join() strip()，翻转用切片
  • 掌握列表特有操作：reverse() remove()
  • 会在字符串与列表间转换

📖 知识点 读一读，会的就点「已会」

知识点 1共有操作
💡 都一样能：+ 拼、* 复制、切片、用 in 问在不在。

字符串和列表很多操作是一样的。

s = "帅气的方块鸟"
lst = [1, 2, 3]
print(s + "老师们")   # 字符串拼接
print(lst + [4, 5])   # 列表拼接
print("红" * 3)         # 红红红
print(2 in lst)        # True
print("块" in s)       # True

拼接/重复生成新对象，原数组不变；in 做成员判断。

知识点 2字符串属性
💡 字符串是『不能改』的，只能靠方法或切片得到新字符串。

字符串不可变，但有很多方法。

s = "a,b,c"
print(s.split(","))       # ["a","b","c"]（拆成列表）
print("-".join(["a","b"]))  # "a-b"（拼回字符串）
print("  abc  ".strip())     # "abc"（去空格）
print("方块鸟"[::-1])        # 鸟块方（翻转用切片）
# "方块鸟"[0]="x"  # 报错！字符串不可改

split() 字符串→列表；join() 列表→字符串，方向相反要记牢。

知识点 3列表属性
💡 列表是『可变』的，能直接改、能就地排序反转。

列表可变，方法就地修改。

lst = [1, 2, 3, 4, 5]
lst.reverse()    # 就地反转
print(lst)       # [5,4,3,2,1]
lst.append(6)
lst.insert(0, 0)
lst.remove(5)    # 删第一个出现的 5
print(lst)

remove(x) 删第一个匹配值；列表没有值会报错。

知识点 4字符串 ↔ 列表
💡 split 把一句话拆成一份份；join 把一份份拼回一句话。

处理文本和数据组时经常互转。

s = "1-2,3-4,5-6"
print(list(s))          # 逐字符拆
print(s.split(","))     # ["1-2","3-4","5-6"]
print(s.split("-"))     # ["1","2,3","4,5","6"]

lst = ["我有", "1只", "小毛驴"]
print("".join(lst))     # 我有1只小毛驴
print("_".join(lst))    # 我有_1只_小毛驴

列表里若有数字，join 前要先 map(str, 列表) 转字符串。

知识点 5处理数字字符串
💡 先 split 拆开，再 map(int) 变数字，sort 排序，join 拼回去。

拆、转、排序、拼。

s = "2*4*5*1*27*3*9"
nums = s.split("*")
nums = list(map(int, nums))
print(max(nums), min(nums))   # 27 1
nums.sort()
print("-".join(map(str, nums)))  # 1-2-3-4-5-9-27

map(int, 列表) 转整数，map(str, 列表) 转字符串。

📌 老师注记
  • 要点：把字符串和列表放一起对比着讲，孩子更容易抓住『共性』和『区别』。
  • 要点：split/join 的方向多看几遍就会，多举例子。
  • 常见错误：试图改字符串的某个字符（字符串不可变）报错。
  • 常见错误：把 split() 的结果当字符串用（其实是列表）。

阅读程序，选项中描述错误的是（　）。 str_a = "Python" str_b = "computer" str_c = str_a[2:4] + str_b[1:3] str_d = str_a[-1:-5:-2] print(str_c) print(str_d)

  • A. str_a 和 str_b 的数据类型都是字符串
  • B. 第 5 行输出 "thom"
  • C. 第 6 行输出 "my"
  • D. 第 7 行输出结果为 6
展开参考答案
答案：C
str_d=str_a[-1:-5:-2]，即从后往前隔一个取，str_a='Python'，结果是 'noy' 之类，不是 'my'（取决于方向），该选项错误。
第 2 题

下列选项中，属于列表的是（　）。

  • A. "red"
  • B. [1, 2, 3]
  • C. 3.14
  • D. True
展开参考答案
答案：B
列表用方括号 []，B 是列表。
第 3 题

字符串 s = "帅气的方块鸟老师们"，用切片取出“方块鸟”。

第 4 题

处理字符串 "2*4*5*1*27*3*9"：输出最大值、最小值，以及排序后用“-”连接的结果。

🖥️ 打开编程页面 ›
展开参考答案
答案：s = "2*4*5*1*27*3*9" nums = list(map(int, s.split("*"))) print(max(nums), min(nums)) nums.sort() print("-".join(map(str, nums))) # 1-2-3-4-5-9-27
split 拆成列表，map(int) 转整数，sorted 再用 join 连接。
