函数与小海龟绘图

def 复用代码，turtle 画出图形

  • 会用 turtle 基本命令画线、转向、画正多边形

📖 知识点 读一读，会的就点「已会」

知识点 1函数 —— 工具箱
💡 函数像工具箱：把常用工具装进去，随取随用。

把一段能重复用的代码包起来起个名。

def add(a, b):
    return a + b

result = add(3, 5)
print(result)   # 8

def greet(name):
    print("你好,", name)

greet("小明")

def 函数名(参数): 函数体缩进；return 返回结果，没有 return 返回 None。

知识点 2参数与返回值
💡 参数是投进去的材料，return 是交回来的成品。

参数是输入，返回值是算出的结果。

def avg(nums):
    return sum(nums) / len(nums)

print(avg([1, 2, 3, 4]))   # 2.5

def divide_round(a, b):
    if b == 0:
        return "除数不能为0"
    return round(a / b, 2)  # 保留两位小数

print(divide_round(10, 3))  # 3.33

round(x,2) 四舍五入保留两位；函数里先用 if 处理边界。

知识点 3小海龟 · 基本命令
💡 小海龟是画笔：前进、后退、转向、抬笔落笔。

turtle 像一支能拐弯的画笔。

import turtle as t

t.forward(100)    # 前进
t.left(90)       # 左转90度
t.pensize(5)      # 画笔粗细
t.pencolor("red") # 画笔颜色
t.penup()         # 抬笔（不画线）
t.pendown()       # 落笔
t.hideturtle()    # 隐藏小海龟
t.done()          # 保持窗口

常用命令：forward/backward、left/right、penup/pendown、pencolor/pensize、circle。end 别忘了 t.done()。

知识点 4画正多边形
💡 每次前进后转 360/n 度，走 n 次就回到原点。

正 n 边形：外角 = 360 / n。

import turtle as t

def draw_polygon(n, length, color):
    t.pencolor(color)
    angle = 360 / n
    for _ in range(n):
        t.forward(length)
        t.left(angle)

draw_polygon(3, 80, "red")    # 正三角形
draw_polygon(4, 100, "blue")  # 正方形
draw_polygon(6, 60, "green")  # 正六边形
t.done()

关键：每次前进后转 360/n 度。n、length、color 参数让函数能画任意正多边形。

知识点 5颜色填充
💡 先告诉海龟『我要上色』，画完再『上色』。

begin_fill 开始，end_fill 填充。

import turtle as t

t.begin_fill()
t.fillcolor("red")
for _ in range(4):
    t.forward(100)
    t.left(90)
t.end_fill()
t.done()

begin_fill() 开始记录，画完封闭图形后 end_fill() 填充。

📌 老师注记
  • 要点：函数先讲『为什么用』（复用、清晰），再讲语法。
  • 要点：小海龟部分孩子很喜欢，多做几个图形（正方形、五角星、风车）。
  • 常见错误：忘写 return 导致拿到 None。
  • 常见错误：正多边形的角度 360/n 算错。
  • 常见错误：忘记写 t.done() 导致窗口一闪而过。

第 1 题

写一个函数 sum_range(n)，计算 0 到 n 的和，并调用输出 sum_range(5)。

🖥️ 打开编程页面 ›
展开参考答案
答案：def sum_range(n): return sum(range(n + 1)) print(sum_range(5)) # 15
range(n+1) 生成 0~n。
第 2 题

写一个画正 N 边形的函数：输入 n（边数）和 a（边长），画出正 n 边形；若 n<3 则结束。

🖥️ 打开编程页面 ›
展开参考答案
答案：import turtle as t def draw_polygon(n, a): if n < 3: return angle = 360 / n for _ in range(n): t.forward(a) t.left(angle) n, a = int(input()), int(input()) draw_polygon(n, a) t.done()
n=3 画正三角形，n=4 画正方形；n<3 直接结束。
第 3 题

用 turtle 画一个边长 100 的蓝色正方形（含颜色填充）。

🖥️ 打开编程页面 ›
展开参考答案
答案：import turtle as t t.pencolor("blue") t.begin_fill() t.fillcolor("blue") for _ in range(4): t.forward(100) t.left(90) t.end_fill() t.done()
begin_fill()/end_fill() 填充封闭图形。
